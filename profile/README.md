## About

**Mfraz** is an independent software organization focused on building **high-performance**, **developer-first**, and **system-oriented** tools.

Mfraz is the home of **Vatts.js** and future experiments around backend systems, protocols, and full-stack tooling.

## Security

If you discover a security vulnerability in any Mfrazlab project, **do not open a public issue**.

Please report it responsibly via email:

📧 **[helpers@mfraz.ovh](mailto:helpers@mfraz.ovh)**

We will review your report and follow up with next steps.
